# Study tracker

App simples para organizar os estudos do dia: cadastre as matérias, marque tarefas, use o cronômetro e veja no relatório quanto tempo foi dedicado a cada uma.

## Processo

1. **Requisitos:** defini o que o sistema precisa fazer, antes de desenhar qualquer tela.
2. **Protótipo de baixa fidelidade:** desenhei as telas à mão, no caderno, para decidir a organização da página.
3. **Protótipo de alta fidelidade:** montei o design no Figma, com cores, tipografia, componentes e a paleta de temas.
4. **Código:** transformei o protótipo em uma página funcional em HTML, CSS e JavaScript, mantendo o design original.
5. **Testes e publicação:** testei cada função e subi o projeto para o GitHub.

## Ferramentas

| Etapa | Ferramenta | Uso |
|---|---|---|
| Baixa fidelidade | Caderno | Rascunho das telas |
| Alta fidelidade | Figma | Design final da interface |
| Estrutura | HTML5 | Página com tags semânticas |
| Visual | CSS3 | Layout, cores e responsividade |
| Lógica | JavaScript | Cadastro, cronômetro, relatório e gráfico |
| Dados | localStorage | Salvar os dados no navegador |
| Tipografia | Google Fonts (Figtree) | Fonte do app |

## Requisitos

**Funcionais**
- RF01: cadastrar estudos
- RF02: marcar estudos como concluídos e excluir estudos cadastrados
- RF03: iniciar, pausar, retomar e finalizar um cronômetro, registrando a duração da sessão

**Não funcionais**
- RNF01: interface simples e intuitiva
- RNF02: responsiva, para diferentes tamanhos de tela
- RNF03: manter estudos e tempos salvos após fechar a aplicação

## Como rodar

Não precisa instalar nada: baixe o projeto e abra o arquivo `index.html` no navegador.
